# Security Policy

Security is a top priority for **Arzing AI**. As an autonomous platform dedicated to smart contract auditing and real-time network monitoring on the Casper Network, we take the security of our own infrastructure and codebase very seriously.

## Supported Versions

Currently, we provide security updates and support for the following versions of the project. Please ensure you are using a supported version.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.0| :white_check_mark: |
| < 1.0.0 | :x:                |

*(Note: If the project is still in pre-release/beta, please state that versions 0.x.x are actively being developed and patched on the `main` branch).*

## Reporting a Vulnerability

If you discover a potential security vulnerability in Arzing AI, please **do not** report it by creating a public GitHub issue. 

Instead, please report it privately by using one of the following methods:

1. **Email or Secure Form:** Please send a detailed report to `[your-project-email@example.com]` or fill out our secure contact form.
2. **GitHub Security Advisories:** If enabled on this repository, you can securely report the issue via the repository's "Security" tab by clicking "Report a vulnerability".

**What to include in your report:**
- A detailed description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue.
- Any suggested mitigations or fixes if you have them.

### Response Timeline

We will acknowledge receipt of your vulnerability report within **48 hours** and strive to send you regular updates about our progress. We kindly ask that you maintain confidentiality until we have had adequate time to investigate and release a fix (typically within 30-90 days, depending on severity).

## Smart Contract Audits

Arzing AI interacts with on-chain smart contracts on the Casper Network (such as the `AuditRegistry`). While our agents are designed to audit contracts, we strongly recommend that any forks or significant modifications to our core infrastructure contracts undergo independent, human-led security audits before being deployed to mainnet environments.
